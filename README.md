# 🍇 Raisin Classification using Gaussian Naive Bayes

## 📌 Overview
This project uses the Gaussian Naive Bayes algorithm to classify raisins into **Kecimen** and **Besni** categories based on their physical measurements.

## 📂 Dataset
- **File:** `Raisin_Dataset.xlsx`
- **Samples:** 900
- **Features:** 7 numerical features
- **Classes:** Kecimen and Besni

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## ⚙️ Methodology
1. Load and inspect the dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Visualize feature distributions and correlations.
4. Encode class labels and split the dataset (80:20).
5. Train the Gaussian Naive Bayes classifier.
6. Evaluate the model using classification metrics and a confusion matrix.
7. Compare hyperparameter values and predict new samples.

## 📊 Results

| Metric | Score |
|---|---:|
| Accuracy | 82.78% |
| Weighted Precision | 83.60% |
| Weighted Recall | 82.78% |
| Weighted F1-Score | 82.59% |

## 🚀 How to Run
1. Clone or download this repository.
2. Install dependencies:
   `pip install pandas numpy matplotlib seaborn scikit-learn openpyxl`
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Upload the dataset and run the cells sequentially.
